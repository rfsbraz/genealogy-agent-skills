# Assignment B: same-hand exemplar comparison

Use comparative palaeography: compare target forms against separately legible examples made by the same writer in the allowed source material. Do not decide using genealogy, word frequency or a familiar record formula.

1. **Locate the target before inspecting exemplars.** Use the marked line view to identify the red target box and blue preceding-word box; inspect the neutral line, anchor and target views for actual ink. Record `method_product.target_location` with `source_id`, `page`, `bbox_original` and `preceding_anchor` (literal reading with uncertainty, or an explicit line-start statement). Freeze this location. Coloured outlines are orientation aids, never letter evidence. A word elsewhere in the line cannot become the target because an exemplar resembles it. If the anchor or target boundary is wrong, request corrected inputs.
2. Locate each sample using **source_id + page + sample_id + bbox_original + asset_id** from inputs.json. Coordinates are local to their source page. Equal coordinates on different pages identify different locations, not contradictory copies. A deduplicated asset can cover multiple aliases: use each sample's own exact bounds within it, not the whole merged area as one word. Compare original and enlarged views. If one sample lacks identity or is unusable, exclude that sample with a reason; retain other valid samples.
3. Check whether each exemplar belongs to the same hand; marginalia can be later additions. Explain uncertainty about the hand rather than assuming it.
4. Identify secure examples of the ambiguous forms and cite exact page/region locations. A disputed target or an unverified transcript cannot label its own exemplar. An exemplar requiring the target reading to be recognized is circular.
5. Compare shape, joins, relative height and the writer's positional variants. Include mismatches and a plausible counterexample. Similarity alone is weaker if the writer uses the same form for several letters. Recheck the frozen target position before returning a word.
6. Return `method_product.exemplar_matches`: target subregion, page-qualified exemplar locator and inspected view ID, exemplar's visible reading and its basis, matched features, differences, and hand-match assessment. Preserve target spelling even if unusual.

Set `execution_kind: same_hand_comparison`. This is visual exemplar matching unless an actual template-matching/distance tool was used; never invent similarity scores. With no secure same-hand examples, return a justified abstention for that span instead of a generic read.
