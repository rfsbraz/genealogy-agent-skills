# Coordinator-only packet index

Build one fresh context for each method below, even when all use the same model. Send [common-contract.md](common-contract.md) and **only one** brief, with that method's scoped inputs. Keep this index, reconciliation policy, earlier answers and the other briefs out of worker contexts.

| Method | Brief | Scope | Distinct result |
|---|---|---|---|
| A | [stroke-analysis.md](stroke-analysis.md) | Original plus enlarged target views | Stroke/grapheme feature inventory; uncertain sequences |
| B | [same-hand.md](same-hand.md) | Target, marked line position, preceding word and page-qualified samples | Fixed target location and cited exemplar correspondences; abstention if unavailable |
| C | [line-recognition.md](line-recognition.md) | Complete lines/tiles plus target details | Frozen line output, segmentation/omission audit and character self-check |
| D | [context-decoding.md](context-decoding.md) | Entry/page plus line/target detail and sourced context | Candidate/constraint table; visible/inferred separation |

A and C intentionally use different scales and decision units. B must ground itself in this writer's exemplars, not generic handwriting familiarity. D may use verified context excluded from A/B/C, but cannot treat a gazetteer hit or a familiar formula as proof of the ink. These prompt-level strategies are inspired by research/practice; they are not four independently trained algorithms.

Use only folders released by `dispatch` after a recorded preflight; never launch from `draft/`. Reuse page assets and coalesce near-duplicate sample views while retaining every sample locator. Use neutral enlarged views, without contrast enhancement. Require final-message responses. A shared filesystem is not enforced isolation. Record actual context IDs in a separate execution log linked to the frozen coordinator manifest and packet digest. Do not mutate the manifest after review. Run serially if concurrency is limited. Do not require model diversity. Use native source references when a local file is unavailable; never propagate an unverified stale path.
