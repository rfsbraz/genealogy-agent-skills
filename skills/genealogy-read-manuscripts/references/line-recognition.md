# Assignment C: whole-line sequence recognition

Read complete target lines as continuous sequences, retaining global spacing, ligatures and alternative word boundaries. Do not force a character-by-character segmentation or consult external family/place context. Do not build a same-hand exemplar dictionary. Language knowledge is inherent to a recognizer; do not describe this as a prior-free or statistically independent reading.

1. Read the complete line first, using the supplied enlarged line tiles in their recorded order when the viewer shrinks the full line. Overlap between tiles is the same text, not repeated words. Preserve that first output as `raw_line_output` before inspecting target close-ups.
2. Use an available suitable HTR recognizer if one is explicitly provided with source access and an appropriate checkpoint. Otherwise use the current vision model to read the complete line directly. These are two implementations of this assigned strategy, not interchangeable algorithm claims.
3. Preserve the raw line output before interpretation. Then inspect the target detail views to audit consequential names, places, digits, negations and kinship words. Record a `character_audit` with each uncertain character/group (especially the ending), its source/page/view locator, visible feature, and verdict: supported, uncertain or contradicted. Keep uncertain characters explicit; a fluent word does not excuse missing or incompatible strokes. Your self-check cannot settle conflicts found in later source review. Look for omitted short words, duplicated words, collapsed abbreviations, merged boundaries, disconnected marks and silently repaired spellings. Report the line order and target span within it.
4. Return `method_product.raw_line_output`, `character_audit`, `line_transcription`, `boundary_alternatives`, `omission_insertion_checks`, and `recognizer`. The recognizer metadata includes actual tool/model/checkpoint/version and decoder settings when known; use unknown values honestly. For a real HTR run retain raw output and model-appropriate uncalibrated scores separately from the final reading.
5. Set `execution_kind: vlm_line_reading` for a prompted visual-model read, or `htr_engine` only for a real tool invocation. A CTC decoder, trained recognizer or TrOCR model is not implemented by mentioning it in a prompt. Do not fabricate an n-best list, logits, character boxes or scores.

If no specialized engine is available, complete the whole-line visual read rather than dropping the method. If the available engine's script/language mismatch makes it unusable, disclose that and use the visual implementation. Do not install models, upload private images or call outside services unless already authorized and supported by the host.
