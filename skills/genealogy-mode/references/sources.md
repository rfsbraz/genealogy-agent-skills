# Method and integration references

Compiled 2026-10-16 from official/professional guidance consulted during design. These are starting references, not installed connectors. Recheck current endpoints, service rules and capabilities before implementation. The procedural skills are an implementation design, not a certification or a reproduction of the publications.

| Reference | Use |
| --- | --- |
| [BCG ethics and standards](https://www.bcgcertification.org/ethics-standards) | Focused research, the Genealogical Proof Standard, documentation, conflict resolution and written conclusions. |
| [APG code of ethics](https://www.apgen.org/code_of_ethics.php) | Clear scope, attributed work, confidentiality and professional communications. |
| [NGS sound research guidelines](https://www.ngsgenealogy.org/wp-content/uploads/NGS-Guidelines/Guidelines_Sound-Research2016-FINAL-30Sep2018.pdf) | Hypothesis testing, originals/best evidence, qualified conclusions and openness to correction. |
| [Evidence Explained, analysis process](https://www.evidenceexplained.com/content/quicklesson-17-evidence-analysis-process-map) | Distinguish source, information and evidence; evaluate dependence and meaningful absence. |
| [NGS responsible AI guidance](https://www.ngsgenealogy.org/wp-content/uploads/2026/01/Responsible-Use-of-AI.pdf) | Verify generated content, disclose material AI contributions appropriately and protect private information. |
| [IIIF overview](https://iiif.io/get-started/how-iiif-works/) | Image delivery, manifests and page structure when implemented by a repository. |
| [OAI-PMH](https://www.openarchives.org/pmh/) | Repository metadata discovery. |
| [FamilySearch developer onboarding](https://www.familysearch.org/innovate/getting-started) | Application approval, environment access and OAuth prerequisites. |
| [Transkribus recognition documentation](https://docs.transkribus.org/processing/text-recognition) | Optional recognition API and layout output. |
| [GEDCOM specifications](https://gedcom.io/specs/) | Genealogical interchange; verify target import/export behaviour. |
| [Gramps Web API](https://www.grampsweb.org/development/backend/api/) | Optional external family-tree adapter. |
| [Inspect AI](https://inspect.aisi.org.uk/) and [agent bridge](https://inspect.aisi.org.uk/agent-bridge.html) | Optional evaluation framework, controlled tools, custom scoring and external agent integration. |
| [Promptfoo assertions](https://www.promptfoo.dev/docs/configuration/expected-outputs/) | Optional deterministic and model-graded evaluation checks. |

For Portugal see genealogy-repository-discovery/references/portugal.md, including official directory and service links. No other country's repositories are pre-verified by this bundle; discover and cite them at runtime.
